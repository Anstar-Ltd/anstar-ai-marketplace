# MVP non-goals and follow-up candidates

Capture these without expanding the first installability/read-access proof.

## Required before a broader Sales rollout

- Server-side filtered read-only MCP gateway or another enforceable equivalent.
- Verified least-privilege Dataverse role and negative access tests for each pilot identity.
- Confirmed ChatGPT workspace plugin publishing and role-assignment path.
- Per-user OAuth flow tested from a second user's fresh machine/account.
- Clear handling policy for activities, notes, attachments, personal contact fields, and prompt retention.
- Audit, rate limits, redaction, incident revocation, rollback, and support ownership.
- Stable user-openable Dynamics URLs and evidence formatting.

## Product improvements after MVP feedback

- Dedicated opportunity-review skill beyond the bounded weekly review.
- Better account-name disambiguation.
- Deterministic stale-opportunity and next-action rules based on live schema.
- Calendar, email, transcript, messaging, enrichment, and public-research sources where approved; the current role MVP intentionally uses only Dataverse.
- Follow-up, deal strategy, business cases, forecasting, coaching, outreach, monitoring automations, and CRM writeback remain excluded rather than copied from the upstream Sales plugin.
- Optional compact table/widget for pipeline review.
- Usage evaluation set based on Ed's real prompts and expected records.
- Marketplace branding, icons, privacy policy, terms, release notes, and version upgrade guidance.
- GitHub Actions for manifest/skill validation and secret scanning.

These are candidates for future ClickUp tasks or subtasks after the local proof and Ed's initial feedback; none are claimed complete by the MVP.
